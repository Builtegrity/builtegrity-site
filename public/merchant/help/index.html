When automatic updates work

Stripe/Square events arrive independently of merchant custom fields. Your other software must send its field updates using an authorized webhook, app automation, or database relay. Once configured, Builtegrity receives those fields automatically; neither you nor Builtegrity staff have to re-enter them.

If your software cannot send updates, you can use the secure field editor or import a CSV/JSON file. These are manual methods—not live integrations.

Bank status reminder: a processor payout marked paid is not the same as a posted bank deposit. Bank updates can take days, and bank access may occasionally need your approval again. Builtegrity will show a reconnect action when required and will not claim final settlement.

Submit an integration request

Tell us which software or data source you want to connect and what you want tracked. Your account saves a ticket number. Requests for unsupported software may require future connector development; submitting a request does not create an instant integration.

Do not submit bank account numbers, access tokens, passwords, customer payment-card details, private files, or API keys. Describe field names and connection needs only. Files can be imported in the Integrations page if appropriately authorized.
