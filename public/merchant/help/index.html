Quick answers

How do custom fields update automatically?

Configure a field once, then connect your existing software to the authenticated HTTPS data feed. It must send matching customer or merchant payment references. New values are recorded as they arrive and appear in transaction details and PDFs; updates are not guaranteed to arrive in the exact same second as a processor event.

My CRM or database doesn't have a Builtegrity connector

If it can send a webhook or you can use an outgoing database relay, choose an automated push source. Otherwise import a structured CSV/JSON file or enter a field manually. If none work, choose “Connect an unsupported system” below and identify the software; do not paste passwords, private API keys or banking credentials.

My bank asks me to authorize again

Only you can renew bank permission. Select Reconnect in your bank settings. Builtegrity's payment monitoring continues, but the bank deposit section will not claim posted deposits until authorized data is available. Bank updates can lag by days; posted does not guarantee irreversible settlement.

Open connected-bank settings →
How do I view or download transaction evidence?

From My Builtegrity, choose Transactions & refunds. Open any row to view its live event history, then select the PDF icon for the current printable record. Its recorded information changes as verified processor and connected custom-source evidence arrives.
